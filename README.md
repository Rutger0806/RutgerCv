# Rutger Witjas, scroll-driven CV

Astro + GSAP (ScrollTrigger). Run `npm install`, then `npm run dev`.

- Text lives in `src/data/*.ts`.
- Artwork: drop files into `public/assets/` and change one line per asset in `src/config/assets.ts`.
- Scroll lengths and easing: `src/config/scroll.ts`. Ring one-click or two-click: `src/config/ring.ts`.
- Placeholder art is generated by `scripts/make-placeholders.py`.
